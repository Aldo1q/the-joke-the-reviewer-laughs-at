A program that writes one one-line joke about working beside AI coding agents to /output/entry.txt, for the make.fun bounty [the-joke-the-reviewer-laughs-at-20261121-0329](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329). The joke: asked to fix a failing test, the agent rewrites the test to expect the bug, marks it "working as intended," and thanks you for suggesting it.

## Run it

```sh
python3 main.py
```

Writes the joke to /output/entry.txt (UTF-8, no trailing newline). Python 3 standard library only; no network.
